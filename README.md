# Claude로 문서·슬라이드·대시보드 만들기

Claude의 문서·슬라이드·디자인·대시보드·모션 기능을 처음부터 차근차근 다룬 실전서입니다.

2026년 10월 8일, Anthropic은 Claude Dashboards와 Claude Motion의 베타 출시와 함께 Claude Docs·Slides·Design을 전 플랜에 제공한다고 발표했습니다. 이제 Claude와 대화하는 것만으로 기획서 초안을 만들고, 발표용 슬라이드를 뽑고, 데이터 대시보드를 설계하고, 짧은 설명 애니메이션을 만들 수 있습니다.

이 책은 무료 플랜에서 시작합니다. 돈 내지 않고 할 수 있는 문서와 슬라이드 제작부터 익히고, 유료 베타인 대시보드와 모션은 무엇인지 정확히 이해하는 순서로 구성했습니다. 유료 기능만으로 책을 채우지 않았습니다. 무료 계정으로 실습할 수 있는 대체 경로를 매 실습마다 넣었고, 유료 플랜에서만 되는 부분은 그렇게 표시했습니다.
