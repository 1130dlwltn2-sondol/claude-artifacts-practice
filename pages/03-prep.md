# 준비물·기능 확인

이 책의 실습을 따라 하려면 아래 준비물이 필요합니다.

## 준비물

- Claude 계정: 무료 플랜으로 시작합니다. claude.ai에서 가입합니다.
- 웹 브라우저: 최신 버전의 Chrome, Edge, Safari 중 하나. 실습은 웹에서 진행합니다.
- 가상 데이터: 책에서 제공하는 예제 데이터를 그대로 쓰세요. 실제 업무 데이터는 넣지 마세요.

## 기능 켜기: 코드 실행과 파일 생성

Claude가 문서·슬라이드·대시보드를 만들려면 설정에서 코드 실행과 파일 생성을 켜야 합니다. 이 설정이 꺼져 있으면 결과물이 만들어지지 않습니다.

1. Claude 웹 화면에서 설정으로 들어갑니다.
2. Capabilities(기능) 메뉴를 엽니다.
3. 코드 실행(Code execution)과 파일 생성(File creation)을 켭니다.
4. Team·Enterprise 플랜에서는 조직 관리자가 조직 설정의 Capabilities에서 켭니다.

설정을 켰는데도 결과물이 안 나오면 이 부분을 먼저 의심하세요. 가장 흔한 원인입니다.

## 내 플랜에서 되는 기능 확인하기 (2026-10-10 기준)

아래 표는 집필일 기준입니다. 요금제와 기능 범위는 바뀔 수 있으니 Claude 공식 요금제 페이지를 함께 확인하세요.

| 기능 | Free | Pro | Max | Team | Enterprise |
| --- | --- | --- | --- | --- | --- |
| 대화에서 문서·슬라이드·디자인 만들기 | 됨 | 됨 | 됨 | 됨 | 됨 |
| Claude Docs·Slides·Design | 됨 | 됨 | 됨 | 됨 | 됨 |
| Claude Dashboards (베타) | 안 됨 | 됨 | 됨 | 됨 | 됨 |
| Claude Motion (베타) | 안 됨 | 안 됨 | 안 됨 | 됨 | 됨 |

참고 사항:
- Docs·Slides·Design은 2026년 10월 15일에 자동 활성화될 예정입니다(HIPAA 적용 조직 제외). 그 전에는 계정·조직 설정을 확인해야 할 수 있습니다.
- Enterprise에서는 Dashboards와 Motion이 기본적으로 꺼져 있습니다. 관리자가 조직 설정의 Artifacts 메뉴에서 켜야 합니다.
- Team·Enterprise에서는 공유 링크가 기본적으로 조직 내부에만 유효합니다. 외부 공유는 관리자가 켜야 합니다.

## 기능 가용성 점검표

실습 전에 아래를 확인하고 기록하세요. 2장에서 다시 씁니다.

- [ ] 내 플랜: Free / Pro / Max / Team / Enterprise (해당 항목에 표시)
- [ ] 코드 실행·파일 생성: 켜짐 / 꺼짐
- [ ] Docs·Slides·Design: 보임 / 안 보임
- [ ] Dashboards (베타): 보임 / 안 보임
- [ ] Motion (베타): 보임 / 안 보임

보이지 않는 기능이 있다면 없는 것으로 실습하세요. 이 책의 모든 실습에는 무료 플랜 대체 경로가 있습니다.
