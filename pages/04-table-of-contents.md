# 전체 목차

표지
판권·사용 안내
머리말
준비물·기능 확인

1장. Claude가 만드는 결과물 이해
- 대화 답변과 편집 가능한 결과물의 차이
- 실습: 가상 프로젝트 메모를 한 페이지 보고서로 정리하기

2장. 플랜·기능·설정 확인
- 무료와 유료 베타 기능 구분하기
- 실습: 내 계정 기준 기능 가용성 점검표 쓰기

3장. 좋은 문서 프롬프트
- 독자·문서 목적·검증 기준 지정하기
- 실습: 가상 동아리 행사 안내문 쓰기

4장. 자료를 넣고 구조화하기
- 원본 데이터와 AI의 추론 분리하기
- 실습: 가상 CSV 10행으로 합계·평균·결측값 분석하기

5장. 슬라이드와 디자인
- 한 장 한 메시지 원칙
- 실습: 문서를 발표용 슬라이드 5장으로 바꾸기

6장. 대시보드 설계와 지표 검증
- 지표 정의·갱신 시각·쿼리 공개의 의미
- 실습: 가상 주문 데이터 대시보드 명세서 쓰기 (무료 대체: 정적 명세서)

7장. 모션 스토리보드와 내보내기
- 코드 기반 애니메이션과 생성 영상의 차이
- 실습: 20초 애니메이션 스토리보드 6컷 쓰기 (무료 대체: 스토리보드 문서)

8장. 최종 프로젝트: 검증 가능한 보고 패키지
- 문서·슬라이드·지표 명세·스토리보드 통합과 감사
