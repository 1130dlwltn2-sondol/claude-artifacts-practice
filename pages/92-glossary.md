# 용어집

Artifact: Claude가 대화 옆 별도 패널에 만드는 결과물. 문서, 슬라이드 덱, 디자인 시안, 대시보드, 애니메이션, 작은 대화형 도구를 통칭합니다. 편집·재방문·공유가 됩니다.

Claude Docs: Claude와 함께 쓰는 문서 기능. 대화에서 시작한 생각을 문서로 만들고, 팀과 동시에 작업할 수 있습니다.

Claude Slides: Claude로 만드는 발표용 덱 기능. 문서나 대화 내용을 슬라이드로 바꾸고, PowerPoint·Google Slides·PDF로 내보낼 수 있습니다.

Claude Design: Claude로 만드는 디자인 시안 기능. 목업이나 한 페이지를 대화로 만듭니다. 예전 독립 사이트는 2026년 12월 14일까지만 유지됩니다.

Claude Dashboards (베타): 데이터 플랫폼에 연결해 평이한 질문으로 만드는 실시간 대시보드. 유료 플랜(Pro·Max·Team·Enterprise)에서 베타로 제공됩니다.

Claude Motion (베타): 보고서나 차트를 짧은 애니메이션으로 바꾸는 기능. 코드로 짜서 단어·숫자·타이밍을 고칠 수 있고 MP4로 내보냅니다. Team·Enterprise 플랜에서 베타로 제공됩니다.

Capabilities: Claude 설정의 기능 메뉴. 코드 실행과 파일 생성을 여기서 켭니다. Artifact를 만드는 전제 조건입니다.

외부 공유: Team·Enterprise에서 조직 밖 사람에게 결과물 링크를 공유하는 설정. 기본적으로 꺼져 있으며 관리자가 켭니다.

쿼리 공개: 대시보드의 숫자를 클릭하면 그 뒤의 쿼리(계산 과정)를 보여주는 기능. 수치 검증의 수단입니다.

스토리보드: 애니메이션을 만들기 전에 쓰는 컷별 기획 문서. 화면 설명, 자막, 시간, 사실/가정 표시를 포함합니다.

검증 기록: 언제, 무엇을, 어떻게 확인했는지를 남긴 기록. 수치 검산과 공개 전 검증의 증거가 됩니다.
